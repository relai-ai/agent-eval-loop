# Changelog

[GitHub Releases](https://github.com/relai-ai/agent-eval-loop/releases) is the canonical release
history. Each release records its source `main` commit, generated change notes, and supplied
project-copy migration notes. Feature PRs describe their changes without bumping versions;
the manual Release workflow pushes tested version bumps to `main` and publishes them directly.

Versions in development manifests can identify unreleased snapshots; use their commit and
local changes to identify them precisely.
